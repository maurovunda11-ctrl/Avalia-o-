Tarefa 1 – Introdução ao CSS

O CSS (Cascading Style Sheets, ou Folhas de Estilo em Cascata) é uma linguagem utilizada para definir a aparência e o layout de páginas web. Ele trabalha em conjunto com o HTML, sendo responsável pela parte visual dos sites, como cores, fontes, tamanhos, espaçamentos e posicionamento dos elementos.

Enquanto o HTML é usado para estruturar o conteúdo de uma página, o CSS permite separar o conteúdo da apresentação, tornando os sites mais organizados, flexíveis e fáceis de manter.

Definição de CSS

CSS é uma linguagem de estilização que controla como os elementos HTML devem ser exibidos na tela, no papel ou em outros meios. Com o CSS é possível criar layouts modernos, responsivos e visualmente agradáveis.

Conceitos Básicos do CSS

Os principais conceitos do CSS incluem:

  • Seletores: indicam quais elementos HTML receberão o estilo.
  • Propriedades: definem o que será alterado, como cor ou tamanho.
  • Valores: especificam como a propriedade será aplicada.
  • Cascata: determina a prioridade das regras de estilo.
  • Herança: permite que alguns estilos sejam herdados dos elementos pais.

O uso correto do CSS é fundamental para o desenvolvimento de páginas web profissionais, acessíveis e compatíveis com diferentes dispositivos, como computadores, tablets e telemóveis.
