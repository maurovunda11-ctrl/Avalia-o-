Tarefa – Seletores CSS

Os seletores CSS são utilizados para indicar quais elementos HTML receberão estilos. Eles permitem aplicar regras de formatação de forma precisa, controlando a aparência de textos, imagens, caixas e outros componentes da página.

Definição de Seletores CSS

Um seletor CSS é a parte da regra de estilo que seleciona o elemento HTML que será estilizado. Através dos seletores, o desenvolvedor define exatamente onde o CSS será aplicado.

Conceito de Seletores CSS

O conceito dos seletores baseia-se na ligação entre o CSS e o HTML. Cada seletor corresponde a um ou mais elementos da página, permitindo que o estilo seja aplicado de forma organizada e eficiente.

Principais Tipos de Seletores

  • Seletor de elemento: seleciona todos os elementos HTML de um determinado tipo.
    Exemplo: p { color: blue; }
  • Seletor de classe: seleciona elementos que possuem uma classe específica.
    Exemplo: .caixa { background: #eee; }
  • Seletor de ID: seleciona um único elemento através do seu identificador.
    Exemplo: #titulo { font-size: 24px; }
  • Seletor universal: aplica estilo a todos os elementos da página.
    Exemplo: * { margin: 0; padding: 0; }

Modos de Uso dos Seletores CSS

Os seletores CSS podem ser utilizados de diferentes formas, dependendo da necessidade do projeto:

  • CSS inline: aplicado diretamente no elemento HTML através do atributo style.
  • CSS interno: definido dentro da tag <style> no arquivo HTML.
  • CSS externo: criado em um arquivo separado (.css) e ligado ao HTML através da tag <link>.

O uso correto dos seletores CSS torna o código mais organizado, reutilizável e fácil de manter, sendo um dos fundamentos essenciais do desenvolvimento web.
